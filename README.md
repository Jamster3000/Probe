# Probe

Probe is a Fabric mod for Minecraft that shows a small set of debugging numbers on screen as a overlay, such as entity count, the most common loaded entity, FPS.

its main feature is recording these numbers over a period of time, like a benchmark, and comparing two recordings to see how performance changes between them.

## Background
Probe was my first Minecraft mod. I built it to learn how modding works. Modding turned out to be more complex than I expected. I found the structure and architecture hard to get a grip on, so I don't plan to make another mod or make changes to this one. Probe is shared here so it shows my attempt and available if it actually provides any use to anyone.

## Features
- Live overlay with various Minecraft numbers.
- Timed recordings that log values to file.
- Comparison of 2 recordings to see how values change.

## Requirements
- Minecraft 26.2
- Fabric Loader 0.19.5
- Java 25
